contextSafe is the other half of the API. The reactive callback is already inside a gsap.context(), but a click handler isn't — so tweens it creates would escape cleanup. Wrapping the handler puts them back under the same context.

The distinction that matters: wrap handlers that create animations. A handler that only writes a signal needs nothing — the callback re-runs and reverts the previous run for you.
