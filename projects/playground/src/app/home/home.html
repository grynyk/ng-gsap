ng-gsap

A signals-first wrapper for using GSAP in Angular, in the spirit of @gsap/react.

@gsap/react's useGSAP hook takes a manual dependency array, same as useEffect. Angular doesn't need that — an effect() already auto-tracks every signal read inside it. So the core primitive, injectGSAP(), wraps your animation callback in an effect: read a signal inside the callback and it becomes a live dependency automatically.
