Every inject* function and signal helper takes an optional injector, needed only when you call it outside an injection context. animationSignals and gsapScrub also take killOnDestroy (default true).

injectGSAP

Returns context (a signal of the live gsap.Context, for imperative escape hatches) and contextSafe. A scope signal that has not resolved yet makes the callback wait, so a selector never escapes to the whole document; it runs as soon as the element exists.

contextSafe

The reactive callback already runs inside the context. A handler defined outside it does not, so the tweens it creates would escape cleanup. Wrap handlers that create animations — and only those.

Wrapping a plain signal write is a common cargo cult. It does nothing.

provideGsap

The configuration is also available as the GSAP_CONFIG injection token, and the router one as GSAP_ROUTE_TRANSITIONS. Every option and handle type is exported (GsapConfig, InjectGsapOptions, GsapHandle, GsapScope, AnimationSignals, ScrollTriggerHandle, RouteTransitionContext, GsapRouteTransitionsConfig and the rest) and covered by the same SemVer promise as the functions.

animationSignals

Kills the animation on destroy by default. Pass {{ '{' }} killOnDestroy: false {{ '}' }} when you are mirroring an animation whose lifetime belongs to something else.

gsapScrub

ng-gsap/scroll-trigger

A trigger signal is waited for, then the trigger re-creates itself whenever the element changes. An animation you pass in stays yours: a re-created or destroyed trigger stops driving it but never kills it, so create it inside injectGSAP and let the context revert it.

Where ScrollTrigger cannot run — during SSR, or under jsdom, neither of which has layout to measure — the handle stays inert and isSupported is false, rather than throwing. Components that use it stay unit-testable.

ng-gsap/router

The leave snapshot is removed when its animation completes, reverse-completes or is killed; an animation that is already finished when you return it removes it at once. Callbacks you set on your own animation (onComplete and friends) keep running, with their params and callbackScope intact.
