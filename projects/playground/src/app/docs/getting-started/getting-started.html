Your first animation

injectGSAP runs its callback inside a gsap.context() wired to Angular's reactivity. You never list what the animation depends on — Angular tracks the signals you read, so changing one re-runs the callback with the previous run already reverted.

Nothing to declare, nothing to clean up. That is the entire idea — everything else in this library follows from it.

What scope does

scope confines every selector string used inside the callback to that element, so '.box' can never reach into another component. Pass a viewChild() signal and the callback waits until it resolves, then runs; an optional view child that is not on screen yet never lets a selector escape to the whole page. You can skip scope entirely if you pass real elements to GSAP instead of selector strings.
